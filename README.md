# Rapid Sec Labs

> Cybersecurity learning & training platform — by RapidBizz.

Practical security learning, built by a Dubai-based team working in cybersecurity every day.

## What it is

Rapid Sec Labs is RapidBizz's own cybersecurity learning initiative: training content and learning material focused on practical skills, not theory-only material.

## Focus areas

- Practical cybersecurity fundamentals
- Vulnerability assessment concepts
- Hands-on learning and training

> Authorised security work only. No unauthorised testing is offered or endorsed here.

## Status

Own initiative of RapidBizz Pvt. Ltd. — in development.

## Stack

React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Supabase.
